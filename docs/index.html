Device-Verified Core Features

Every feature below was compiled from Chromium 160 source and physically verified on Samsung Galaxy S25 Ultra (SM-S938B, Android 17).

🧩

Desktop MV3 Extensions on Phones

Built with is_desktop_android = true and patched for smartphone toolbars (ToolbarPhone → ViewGroup). Includes Extensions, Manage Extensions (chrome://extensions), and Chrome Web Store right inside the 3-dot menu.

🛠

Tab-Native Developer Tools

Enables kAndroidDevToolsFrontend on phones and inserts DevTools directly into ChromeTabbedActivity's TabModel as a regular browser tab — keeping the inspected tab alive at MODERATE process importance.

🔍

On-Device chrome://inspect/#devices

Compiles and registers InspectUIConfig on Android. Immediately lists Kiwi Next (Local Device) open tabs, extension background pages, and service workers with inspect, pause, focus tab, reload, and close.

🤖

Native Loopback CDP (127.0.0.1:9222)

Binds Android's DevToolsServer to TCP 127.0.0.1:9222 with --remote-allow-origins=*, bypassing Android 17 SELinux abstract-socket blocks so chrome-devtools-mcp and Antigravity /browser connect directly.

⚡

kiwi_mcp_bridge v1.1.0 Extension

Manifest V3 companion extension connecting over ws://127.0.0.1:9223 with chrome.debugger Runtime.evaluate, raw cdp_send, tab management, and PNG viewport capture.

🌙

AMOLED Dark Mode & Kiwi Identity

Tunes Blink's dark-mode foreground brightness threshold from 150 to Kiwi's high-contrast AMOLED preset (127), packaged cleanly as com.kiwibrowser.next with the white Kiwi adaptive launcher icon.

Native CDP (:9222) & MCP Bridge (:9223)

Shizuku Installation & Background CDP Tip

Install the signed ARM64 APK directly on your device or via Shizuku (rish). On Android 15–17, whitelisting com.kiwibrowser.next from battery optimization keeps port 9222 responsive while using AI agents in another app. 

# Install via Shizuku (no root required)
rish -c "cp /storage/emulated/0/Download/kiwi-next-arm64-v160.0.8157.3.apk /data/local/tmp/kiwi-next.apk"
rish -c "chmod 666 /data/local/tmp/kiwi-next.apk"
rish -c "pm install -r -d /data/local/tmp/kiwi-next.apk"
rish -c "rm -f /data/local/tmp/kiwi-next.apk"

# Prevent Android cached-app freezer from pausing CDP port 9222 in background
rish -c "dumpsys deviceidle whitelist +com.kiwibrowser.next"
rish -c "cmd appops set com.kiwibrowser.next RUN_ANY_IN_BACKGROUND allow"
rish -c "am set-standby-bucket com.kiwibrowser.next active"
