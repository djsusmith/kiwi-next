🤖 Built-in Model Context Protocol (MCP) Bridge

Kiwi Browser Reborn includes a native Manifest V3 tool provider in extensions/kiwi_mcp_bridge/. It connects to your local AI coding agent over ws://127.0.0.1:9223, giving agents structured tools to interact with your live browser:

list_tabs Inspect open tabs, URLs, and active status.
navigate Command the browser to load any website URL.
eval_js Evaluate scripts directly in the page DOM context.
capture_screenshot Grab crisp PNG viewport captures for vision models.

Kiwi Browser Reborn is an independent community project based on the open-source Kiwi Browser & Chromium codebases.
