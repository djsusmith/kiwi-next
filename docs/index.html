🤖 Built-in Model Context Protocol (MCP) Bridge

Kiwi Next includes a native Manifest V3 tool provider in extensions/kiwi_mcp_bridge/. It connects to your local AI coding agent over ws://127.0.0.1:9223, giving agents structured tools to interact with your live browser:

list_tabs Inspect open tabs, URLs, and active status across windows.
navigate Command the browser to load any website URL programmatically.
eval_js Evaluate scripts directly in the client-side DOM context.
capture_screenshot Grab crisp PNG viewport captures for vision models.
# Direct chrome-devtools-mcp connection (native loopback CDP on port 9222):
chrome-devtools-mcp --browserUrl=http://127.0.0.1:9222
